## 8. Microsoft Edge WebDriver Startup Validation

The script must use Microsoft Edge and Selenium EdgeDriver exclusively.

During browser initialization, detect failures caused by:

- Missing `msedgedriver.exe`
- An invalid driver path
- Edge and EdgeDriver version incompatibility
- An outdated EdgeDriver
- A corrupted driver executable
- A driver process that cannot start
- Permission or access errors affecting `C:\Selenium`
- Other `WebDriverException` errors that prevent Microsoft Edge from starting

If EdgeDriver initialization fails:

1. Stop the entire test execution immediately.
2. Do not mark individual web environments as failed because no functional test started.
3. Dispose of any partially initialized browser or driver process.
4. Write the complete technical error to the local log.
5. Do not expose credentials or sensitive configuration values.
6. Display a non-expiring popup window.
7. Open Microsoft Edge using the official Edge WebDriver download page:

https://developer.microsoft.com/en-us/microsoft-edge/tools/webdriver?form=MA13LH&ch=1&cs=3487937218

The popup must remain visible until the user presses a `Close` button. It must not close automatically and must not have a timeout.

### Required Popup Information

The popup must explain:

- Microsoft Edge WebDriver could not be initialized.
- The installed EdgeDriver may not match the installed Microsoft Edge version.
- How to check the installed Microsoft Edge version:
  1. Open Microsoft Edge.
  2. Navigate to `edge://settings/help`.
  3. Record the complete version number.
- How to check the current EdgeDriver version:
  1. Open Command Prompt.
  2. Run:
     `C:\Selenium\msedgedriver.exe --version`
- The major version of Microsoft Edge and EdgeDriver must match.
- The correct driver must be downloaded from the official Microsoft page.
- The existing driver must be replaced in:
  `C:\Selenium`
- Microsoft Edge and all existing `msedgedriver.exe` processes should be closed before replacing the executable.
- The script must be restarted after the driver is updated.

The popup should also display the original initialization error in a technical-details section when it is safe to do so.

Use `Process.Start` safely to open the URL in Microsoft Edge. If Edge cannot be started explicitly, fall back to opening the URL through the operating system's default HTTPS handler.

## 21. Failure Handling

Apply the following failure rules:

### Global Prerequisite Failure

Examples:

- Invalid configuration
- Missing username or password
- Missing shipment parameters
- Missing image file
- EdgeDriver startup failure
- User cancellation

Required behavior:

- Stop all execution.
- Do not continue to other URLs.
- Dispose of acquired resources.
- Display a clear user-facing message.
- Record the technical details locally.
- Send a Power Automate notification only if the existing architecture supports reporting prerequisite failures safely.

### Environment Failure

Examples:

- A URL is unavailable.
- Login fails on one environment.
- A country workflow fails.
- A required page element is missing.

Required behavior:

- Mark that environment as failed.
- Capture the target URL, country, step, and sanitized error.
- Continue to the next environment during a Full Test, unless continuing would be unsafe or impossible.
- Calculate the global result after all selected environments are processed.

### Step Failure

Required behavior:

- Stop the remaining steps for the affected country.
- Record the country result as failed.
- Determine whether the next country can safely run.
- If necessary, restart the browser session before the next country.
- Do not report a false pass for partially executed workflows.
